# 마음의 해부학

원제는 I'm OK–You're OK다. 저자는 토머스 해리스(Thomas A. Harris)다. 원서 저작권은 1967, 1968, 1969년이다. 한국어판은 21세기북스가 2008년에 냈다. 옮긴이는 조성숙이다. 1판 1쇄는 2008년 5월 19일이고, 발행일은 2008년 5월 29일이다. 역자 서문은 2008년 5월이다.

상태: `reference`. 검사 방법과 수치는 없다. 채점은 90문항, 2020-04-01 컷, 시간 60문항을 유지한다. 사례와 본문은 옮기지 않았다. 설명 요지는 [explanations.md](./explanations.md)에 있다.

스캔은 `_0001`부터 `_0173`까지 173장이고 빠진 번호는 없다. `[Originals]`는 같은 173장의 사본이다. `picture-4.jpg`, `picture-5.jpg`, `picture-45.jpg`는 작은 그림 파일이다.
