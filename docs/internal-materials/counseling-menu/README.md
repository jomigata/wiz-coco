# 상담 프로그램 메뉴 초안

출처는 `상담 프로그램 메뉴 정리중.xlsx`이다. 파일 이름대로 정리 중이며, 네 시트가 서로 겹친다. 어느 시트를 메뉴 기준으로 쓸지는 확인 전이다. 앱 메뉴에는 넣지 않았다.

| 시트 | 보관 | 내용 |
|---|---|---|
| `1. 개인.단체.기관용 종합프로그램` | [sources/01-short-four-columns.txt](./sources/01-short-four-columns.txt) | 단체·개인·고민·교육 네 열의 짧은 목록 |
| `1. 개인.단체.기관용 종합프로그램 (추가)` | [sources/02-expanded-dual-list.txt](./sources/02-expanded-dual-list.txt) | 100개 이상 목록과 200개 이상 목록을 나란히 둔 초안 |
| `최적화된 상담 프로그램 메뉴 구성 (초기구성)` | [sources/03-optimized-early.txt](./sources/03-optimized-early.txt) | 대·중·소분류 메뉴가 두 열로 거의 같이 있음 |
| `AI 심리검사 프로그램 상세 메뉴 구성 (검사명 버전)` | [sources/04-test-title-version.txt](./sources/04-test-title-version.txt) | 왼쪽은 약어를 붙인 검사명, 오른쪽은 평범한 소분류 이름 |

왼쪽 열의 PSTI, TDI, SIRI, NATI, EISI 같은 약어는 출판된 검사 이름이 아니다. 초안 제목으로만 보관하고, 검사 도구로 채택하지 않는다.

우울, 외상, 중독, 자살 생각처럼 임상 주제가 메뉴 이름으로 들어 있다. 여기는 메뉴 문장만 보관한다. 선별 절차나 문항은 이 파일에 없다.
