# 상담 프로그램 메뉴

출처는 `상담 프로그램 메뉴 정리중.xlsx`이다. 2026-10-01 확인으로 네 시트를 모두 참조하여 하나의 목록으로 합쳤다. 기준 목록은 [menu.md](./menu.md)와 [menu.json](./menu.json)이다. 앱 화면에는 넣지 않았다.

| 시트 | 반영 |
|---|---|
| 짧은 4열 | 현장 프로그램. 단체·개인·고민·교육 |
| 확장 목록 | 번호 있는 대상·고민·성장 프로그램 이름을 더함 |
| 최적화된 초기구성 | 겹치는 제목은 아래 검사명 버전의 평범한 이름으로 바꿈 |
| 검사명 버전 | 오른쪽 소분류를 주제 메뉴 이름으로 씀. 같은 소분류의 세부 문장은 양쪽을 합치고 중복은 뺌 |

PSTI, TDI, SIRI, NATI, EISI 같은 약어는 메뉴 이름이 아니다. 주제 항목 옆의 초안 별칭으로만 남아 있다.

원문 철자 `솔로 맟춤형`은 현장 메뉴에서 `솔로 맞춤형`으로 두었다.

우울, 외상, 중독, 자살 생각처럼 임상 주제가 메뉴 이름으로 들어 있다. 여기는 메뉴 문장만 둔다. 선별 절차나 문항은 없다.

네 시트의 원문 추출은 [sources/](./sources/)에 있다.

접수·회기·종결 서식은 [상담 양식](../counseling-forms/README.md)이다. 메뉴 이름과 별개이고, 채점은 없다.
