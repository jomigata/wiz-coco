# 현대의 교류분석

원제는 TA Today: A New Introduction to Transactional Analysis이다. 저자는 Ian Stewart, Vann Joines이고, 원서 저작권은 1987년이다. 한국어판은 학지사가 2010년에 냈다. 공역은 제석봉, 최외선, 김갑숙, 윤대영이다. 역자 서문은 2010년 4월이다. 국제교류분석협회의 TA 101 교육 자료로 쓰라고 적혀 있다.

상태: `reference`. 검사 방법과 수치는 쓰지 않는다. 채점은 90문항, 2020-04-01 컷, 시간 60문항, 스트로크 25문항을 유지한다. 본문과 연습문제는 옮기지 않았다. 설명 요지는 [explanations.md](./explanations.md)에 있다. 학파 3개(고전, 재결단, 커넥시스)는 바꾸지 않는다.

스캔은 `TT_001`부터 `TT_449`까지 419장이다. 없는 번호는 10, 20, 21, 32, 33, 48, 86, 95, 114, 134, 146, 147, 160, 174, 216, 249, 294, 295, 314, 328, 346, 356, 368, 369, 380, 388, 406, 424, 425, 436이다.
