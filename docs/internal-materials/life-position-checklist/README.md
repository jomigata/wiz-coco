# 인생 태도 점검표 40문항

출처는 `검사 - 인생태도점검표.hwp`, 제목은 `Ⅴ. 인생 태도(삶의 자세) 점검표(KTAA식)`이다. 상태는 `kept-separate`이다.

90문항 오케이그램의 U−, U+, I+, I− 문항 번호와 다르다. 인생태도 차이값 NP−CP, FC−AC도 이 합계로 바꾸지 않는다. 별도 점검표로 둔 상태는 확인 전이다.

보기는 `매우 긍정`, `약간 긍정`, `보통`, `약간 부정`, `매우 부정`이다. 숫자는 이 파일에 없다.

문항 오른쪽 네 칸에서 빈 칸이 있는 열이 그 문항의 척도다. 열 순서는 표 하단 `U- U+ I+ I-`이다. 척도마다 10문항이다.

| 척도 | 문항 |
|---|---|
| U− | 6, 10, 14, 18, 22, 25, 29, 32, 35, 37 |
| U+ | 1, 4, 9, 15, 17, 21, 23, 28, 30, 39 |
| I+ | 2, 3, 7, 11, 12, 16, 20, 33, 34, 36 |
| I− | 5, 8, 13, 19, 24, 26, 27, 31, 38, 40 |

문항 문장은 [items-40.json](./items-40.json)에 있다.
