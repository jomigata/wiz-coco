# 인생 태도 점검표 40문항

출처는 `검사 - 인생태도점검표.hwp`, 제목은 `Ⅴ. 인생 태도(삶의 자세) 점검표(KTAA식)`이다. 상태는 `kept-separate`이다.

2026-10-01 확인. 문항 오른쪽 흰 칸이 있는 열은 왼쪽부터 CP, NP, FC, AC다. 표 하단에 인쇄된 `U- U+ I+ I-`는 쓰지 않는다. 척도마다 10문항이다.

이 합계는 90문항 오케이그램의 U−, U+, I+, I−와 다르다. 인생태도 차이값 NP−CP, FC−AC도 이 합계로 바꾸지 않는다.

보기는 `매우 긍정`에서 `매우 부정`까지이고, 점수 범위는 5~1이다. 개인이 적은 점수는 그 사람의 응답이라 기준 컷으로 쓰지 않는다.

|---|---|
| CP | 6, 10, 14, 18, 22, 25, 29, 32, 35, 37 |
| NP | 1, 4, 9, 15, 17, 21, 23, 28, 30, 39 |
| FC | 2, 3, 7, 11, 12, 16, 20, 33, 34, 36 |
