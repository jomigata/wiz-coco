# 오케이그램 점검표 40문항

출처는 `검사 - 인생태도점검표.hwp`이다. 상태는 `kept-separate`이다.

2026-10-01 확인. 이 표는 칸이 4개인 오케이그램이다. 왼쪽부터 CP, NP, FC, AC다. 이고그램의 5칸(CP, NP, A, FC, AC)과 다르다. 표 하단에 인쇄된 `U- U+ I+ I-`는 쓰지 않는다.

| 칸 | 뜻 | 문항 |
|---|---|---|
| CP | 타인부정 | 6, 10, 14, 18, 22, 25, 29, 32, 35, 37 |
| NP | 타인긍정 | 1, 4, 9, 15, 17, 21, 23, 28, 30, 39 |
| FC | 자기긍정 | 2, 3, 7, 11, 12, 16, 20, 33, 34, 36 |
| AC | 자기부정 | 5, 8, 13, 19, 24, 26, 27, 31, 38, 40 |

90문항 오케이그램의 문항 번호와는 다르다. 인생태도 차이값은 그대로 NP−CP, FC−AC다.

보기는 `매우 긍정`에서 `매우 부정`까지이고, 점수 범위는 5~1이다. 개인이 적은 점수는 그 사람의 응답이라 기준 컷으로 쓰지 않는다.

문항 문장은 [items-40.json](./items-40.json)에 있다. 2026-10-01 6차에서 이 번호표는 채점 키로 쓰지 않는다. 채점은 90문항이다. 인생태도의 설명은 [1999년 매뉴얼 요지](../ta-theory-practice/explanations.md)를 본다.

발표 정리의 `302`는 이 40문항과 같고, 빈 칸이 열이다. `301`의 24+24문항은 표식 배정이 파일에 없어 채점에 쓰지 않는다. 메모는 [발표 정리](../presentation-notes/README.md)에 있다.
