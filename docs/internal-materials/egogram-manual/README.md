출처는 2020-04-02 오타정리 원고다. 243 해석 문장은 [기존 202코드](../ego-ok/patterns-243-reports.json)와 같아서 다시 넣지 않았다. 없는 41개 코드도 이 원고에 없다. 앞부분만 새 자료다. 원문 발췌는 [source-before-243.txt](./source-before-243.txt)에 있다.

90문항 기준, 2020-04-01 점수 컷, 시간구조화 60문항은 이 원고로 바꾸지 않는다.

## 구성

1. 이고그램 정의, 역사, 자아상태.
2. 1996년 협회 조사 안내와 인구통계 문항.
3. 이고그램 점검표. 칸은 5개라는 설명만 쓴다. 문항 번호와 긍정·부정 배정은 2026-10-01 6차에서 채점에 쓰지 않기로 했다. 파일은 [items-60.json](./items-60.json).
4. 1994년 한국 표준, 3등급 표, 2000년 예측, 21세기 이념형. 숫자는 [norms-1994.json](./norms-1994.json). 참고만 하고, 채점은 2020-04-01 표를 쓴다.
5. 전형 23패턴. (5)의 원고 이름 대두형은 산형으로 통일한다.
6. 자아상태를 높이는 기법·말·태도. 채점 규칙은 아니다.

## 채점에 쓰지 않는 번호

2026-10-01 6차. 이 원고의 문항 번호, 긍정·부정 짝, AC+의 8번·18번 차이는 무시한다. 채점은 90문항과 2020-04-01 컷만 쓴다. 칸 5개(CP, NP, A, FC, AC)와 뜻(CP 타인부정, NP 타인긍정, FC 자기긍정, AC 자기부정)은 5차에서 정한 설명을 유지한다.
