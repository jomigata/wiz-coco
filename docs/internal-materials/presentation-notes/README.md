# 발표용 텍스트 정리

출처는 `TA\자료-발표\_Text 정리함`이다. 상태: `reference`. 채점은 [90문항](../ego-ok/README.md)과 2020-04-01 컷을 그대로 쓴다. 책 요지, 243 문장, 기도문, 게임 목록, 척도 문항은 다시 옮기지 않았다.

## 책 요지

| 파일 | 처리 |
|---|---|
| `001`, `101`, `심성교류분석_요약정리.xlsx` | 『심성개발』 요지. 엑셀은 시트 1만 있고 2·3은 비어 있다. 학파는 고전, 재결단, 커넥시스 셋이다. 노트에 있는 「3개 학파를 넘어서」는 넷째 학파로 넣지 않는다. 노트는 책의 60여 개국을 70여 개국으로 고쳐 적고, 한국교류분석협회를 2006년 69번째 회원국으로 적는다 |
| `002`, `003` | 『마음의 해부학』 요지. `003`은 1장 기억의 재연까지다. 사례는 옮기지 않았다 |
| `005. 에릭번의_심리게임` | 게임 책의 목차 메모. 어루만짐, 자아상태, 게임의 요소, 시간의 구조화, 절차와 의례, 심심풀이, 게임 대사전, 게임에서 나오기, 자율. 이론 말의 친밀은 시간 구조화 6번 척도 이름 친교와 바꾸지 않는다. 게임 목록은 두지 않았다 |
| `004. 상담의과정과 대화기법` | 2011-07-12 초기 상담 메모. 구조화, 계약, 비밀, 한계, 라포, 동기, 초기 저항이 제목이다. 절차는 옮기지 않았다 |
| `102. 임상_교류분석(요약)` | 정의와 영역(상담, 심리치료, 교육, 조직). 기본 단위는 교류, 실천 기법은 스트로크라고 적는다. 37쪽 문장은 어버이를 어린 시절의 재연으로, 아이를 부모 모방으로 바꿔 적었다. 그 문장은 쓰지 않는다. 어버이는 부모 역할의 재생이고, 아이는 자기 어린 시절의 재생이다 |
| `교류분석 개인상담` | 선입관 없이 보는 관찰, 사회적 말과 심리적 말, 이면 메시지, 진짜 의사, 허가·보호·능력. 예시 대화는 옮기지 않았다 |

## 이미 있는 자료

`203. 금지령_12가지`는 심성개발 360–362쪽이고, 열두 이름은 [이론 요약](../ta-overview/source-outline.txt)과 같다. 메시지와 결단 문장은 두지 않았다.

`212. 이고그램을 높이는 기법 및 태도`의 기법 이름은 [이고그램 원고](../egogram-manual/README.md)의 표와 같다. 의자, 베개, 운전 같은 절차는 옮기지 않았다. `211`은 다섯 자아상태를 켜는 행동 목록이다. 목록은 두지 않았다.

`213. 이고그램 해석(234)`에 실제로 있는 글자 코드는 33개다. 33개 모두 기존 202코드 안에 있다. 파일 이름의 234와 개수가 다르다. 문장은 다시 넣지 않았고, 비어 있는 41개 코드도 그대로다.

`302`는 이미 보관된 40문항 오케이그램이다. 빈 칸이 그 문항의 열이다. 하단의 U− U+ I+ I−는 여전히 쓰지 않고, 이 번호는 채점 키가 아니다.

`202. 게슈탈트의 기도`는 협회 안내서 3쪽과 같은 종류다. 본문은 두지 않았다.

## 채점에 넣지 않는 점검표

`301. 인생태도 체크리스트`는 자기 24문항, 타인 24문항이다. ○는 2, △는 1, ×는 0이고, 네 표식은 자기긍정, 자기부정, 타인긍정, 타인부정이다. 어느 문항이 어느 표식인지는 이 파일에 없다. 90문항 인생태도 식은 바꾸지 않는다. 문항은 옮기지 않았다.

## 낱말과 그림

`201. 감정표현단어`는 느낌 낱말 모음이다. 한쪽은 기쁨, 사랑, 고요, 활기, 유능, 자신감, 배려, 공손이고, 다른 쪽은 성냄, 미움에서 시작한다. 낱말 목록은 두지 않았다.

`204. 스트로크 사례연구`는 심성개발에 실린 두 이야기다. 음식과 시설보다 살과 살이 닿는 접촉이 아이를 살렸다는 결론만 둔다.

그림 네 장이다.

- `TA101(Kr)`, `TA101(En)`은 같은 지도다. 한국교류분석상담학회 서울3지부, TA심리상담코칭센터(박용민). 가지는 교류와 스트로크와 시간, 게임, 라켓, 인생태도와 각본, 방법, 그리고 정의·철학·계약·역사·자아상태다.
- `기능분석 5가지`는 비판적 어버이, 양육적 어버이, 어른, 자유로운 어린이, 순응하는 어린이마다 긍정과 부정을 한 줄로 적는다. 채점 칸은 아니다.
- `스트로크,시간의 구조화`는 두 줄이다. 스트로크는 마음의 영양이고, 시간의 구조화는 게임에서 빠져나오는 시간 사용이다.
- `TA와 프로이드의 차이점`은 둘 다 현재 문제를 과거에서 보되, 프로이트 쪽은 과거를 바꿀 수 없다는 결정론이고 번 쪽은 각본을 지금 고칠 수 있다는 재결단으로 적는다.
