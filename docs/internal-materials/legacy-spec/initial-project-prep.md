# 초기 종합 프로젝트 준비물

출처: `검사 - 초기 종합 프로젝트 준비물.xlsx`

예전 주소 `http://ptest1.iwinv.net`, 그누보드(PHP, MySQL)에 심리검사를 넣기 위한 제작 메모다. 위즈코코 화면 명세로 쓰지 않는다. 검사 운영 방식만 아래에 남긴다.

## 실시 방법

1. 개인회원: 로그인 후 개인정보와 문항을 진행한다. 끝나면 결과확인코드·비밀번호를 만들고 로그인 이메일로 보낸 뒤 결과 조회로 간다.
2. 그룹·전문가: 로그인 없이 검사코드·비밀번호가 맞으면 진행한다. 개인정보에 이메일과 개인고유번호를 더한다. 개인고유번호는 검사번호, 학번, 사번, 회원번호, 이름, 이메일, 휴대폰 등이 될 수 있다고 적혀 있다.
3. 화면은 PC·모바일 대응.

검사코드는 연도 2자리 + 주 2자리 + 일련번호 예) `2052-0001`. 비밀번호는 무작위 4자리.

## 개인정보 (시트 `1.개인정보입력`)

모두 필수.

| 항목 | 선택값 |
|---|---|
| 이름 | 성 1자만 (유출 방지라고 적힘) |
| 출생년도 | 예: 1988 |
| 거주지역 | 17개 시·도 |
| 성별 | 남성, 여성 |
| 결혼 | 미혼, 기혼 |
| 가족 | 1명, 2명, 3명, 4명, 5명 이상 |
| 학력 | 무학, 초졸, 중졸, 고졸, 대재, 대졸 이상 |
| 종교 | 무교, 기독교, 천주교, 불교, 원불교, 이슬람교, 기타 |
| 직업 | 자영업, 주부, 학생, 종교인, 사무직, 생산직, 농업, 임업, 수산업, 기타(무직 포함) |
| 동의 | 서비스 이용약관, 개인정보 취급방침 |

같은 파일의 심리검사 시트 예시에는 성명 `김태호`, 생년월일 `1987.10.10`처럼 전체 이름이 나온다. 성 1자 규칙과 같지 않다.

## 문항 수 기술

심리검사 시트는 `이고그램 50 + 오케이그램 40 + 성실도 10 = 100문항`이라고 적는다. 실제 문항 시트는 95개다.

2026-09-30 확인: 기준 문항은 90개이고 페이크 문항은 넣지 않는다. 이 파일의 95문항·100문항 설명은 기준이 아니다. 채점 번호는 [90문항 기준본](../ego-ok/README.md)을 따른다.

## 결과 관리

- 결과 확인은 로그인, 또는 결과확인코드+비밀번호.
- 관리자·전문가만 결과 관리 목록을 본다.
- 그룹명·그룹코드·비밀번호, 결과 보기 페이지 구성을 전문가별로 만든다.
- 그룹에 검사코드가 연결되어 있으면 그룹 삭제를 막는다.
- 쓰지 않은 검사코드만 일괄 삭제한다.
- 결과 화면에서 인쇄, PDF, 엑셀, 이메일 첨부를 요구한다.

## 약관·개인정보 문장

시트 `1a.서비스이용약관`, `1b.개인정보취급방침`은 운영 주체가 **한국심리검사**로 되어 있다. 개인정보 문장에는 진흥원 홈페이지, 알코올 치료 여부, 뉴스레터, 보유기간 영구 같은 다른 기관 서식 문장이 섞여 있다. 위즈코코 약관이나 개인정보 처리방침으로 가져오지 않았다.
