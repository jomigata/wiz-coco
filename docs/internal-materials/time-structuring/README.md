# 시간 구조화

같은 이름인데 문항 수와 문장이 달라, 한 검사로 합치지 않았다.

## 48문항 체크리스트

- 파일: [v48-checklist.json](./v48-checklist.json)
- 짧은 평서문. 가족·일상 표현이 많다.
- 5점 척도: 매우 그렇다(5), 자주 그렇다(4), 그저 그렇다(3), 별로 그렇지 않다(2), 거의 그렇지 않다(1).
- 원문 1점 표기는 `강항 부정`이다. 오탈자로 보고 보관본 척도 설명만 `강한 부정`으로 적었다. 문항 문장은 원문 그대로다.
- 각 문항은 ■ 여섯 칸 중 □ 한 칸에 점수를 적는다. `scoreColumn`이 그 칸(1~6)이다. 칸의 척도 이름은 파일에 없다.
- 21번 다음과 48번 다음에 소계·합계 칸이 있다.

## 60문항 점검표

- 파일: [v60-items.json](./v60-items.json)
- 질문형(`당신은 … 합니까?`). 학교·공부 장면이 많다.
- 5점 척도: 매우 그렇다(5), 약간 그렇다(4), 보통이다(3), 약간 그렇지 않다(2), 매우 그렇지 않다(1).
- 시트 `문항별검사용`과 `검사샘플`의 문항 문장은 같다. `검사샘플`은 중복본이다.
- 맨 아래 척도 이름은 폐쇄, 의식, 잡담, 활동, 게임, 친교다. 어떤 문항이 어느 척도인지는 적혀 있지 않다.
- 채점표는 30번과 60번 다음에 소계, 맨 아래에 합계가 있다. 칸 값은 모두 0인 빈 양식이다.

## 겹치는 방식

번호가 같다고 같은 문항이 아니다. 주제가 가까운 쌍은 있으나(아침 인사, 식사 대화, 혼자 있기, 재치 있는 말 등), 48문항에만 있는 문항과 60문항에만 있는 문항이 둘 다 있다. 60문항은 학생 장면으로 바꿔 쓴 확장본으로 보이지만, 문항이 1:1로 대응하지는 않는다.

## 원문에 그대로 둔 표기

- 60문항 29번 `댓가` (대가의 오탈자로 보임)
- 60문항 45번 `당신은 길에서 버스, 전철역에서 위험에처한 사람을 돕습니다` — 다른 문항과 달리 물음표가 없고 문장이 끊긴 듯하다
- 48문항 19번 `상대와 충동하는` — 60문항의 대응 문장은 `상대와 부딪친`이다
