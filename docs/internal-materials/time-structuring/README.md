# 시간 구조화

기준은 60문항이다. 48문항 CSV는 확인 후 쓰지 않기로 했다.

## 60문항 점검표

- 파일: [v60-items.json](./v60-items.json)
- 출처: `검사 - 시간의구조화 60문항.xlsx` 시트 `문항별검사용`
- 질문형. 5점: 매우 그렇다(5), 약간 그렇다(4), 보통이다(3), 약간 그렇지 않다(2), 매우 그렇지 않다(1).
- 각 문항 오른쪽 여섯 칸 중 흰 칸이 척도다. 열 순서는 아래와 같고, 척도마다 10문항이다.

| 번호 | 척도 | 문항 |
|---|---|---|
| 1 | 폐쇄 | 11, 14, 20, 23, 26, 42, 47, 52, 54, 56 |
| 2 | 의식 | 3, 5, 7, 10, 17, 24, 36, 41, 48, 55 |
| 3 | 잡담 | 4, 18, 19, 25, 28, 30, 34, 37, 40, 60 |
| 4 | 활동 | 1, 6, 8, 32, 45, 46, 50, 53, 58, 59 |
| 5 | 게임 | 9, 12, 13, 22, 29, 33, 38, 43, 44, 57 |
| 6 | 친교 | 2, 15, 16, 21, 27, 31, 35, 39, 49, 51 |

시트 `검사샘플`은 같은 흰 칸에 예시 점수가 적혀 있다. 그 숫자는 1~5점 예시이고 척도 번호가 아니다.

45번 문장은 확인에 따라 다음으로 고쳤다.

`당신은 길이나 버스나 전철역에서 위험에 처한 사람을 돕습니까?`

`문항별검사용` 시트에는 아직 옛 문장(`길에서 버스, 전철역에서 위험에처한 사람을 돕습니다`)이 남아 있다. 보관본은 고친 문장을 쓴다.
