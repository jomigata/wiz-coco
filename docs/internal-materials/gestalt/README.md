# 게슈탈트 치료 강의 노트

출처는 `게슈탈트치료(B5).hwp`이다. 상태는 `reference`이다. 교류분석 3개 학파(고전, 재결단, 커넥시스)에 넣지 않는다. 채점 문항이 없다.

원문 정리는 [source-notes.txt](./source-notes.txt)에 있다.

## 구성

1. 이론 배경. 펄스(Perls), 유기체 이론, 알아차림.
2. 주요 개념. 게슈탈트, 전경과 배경, 미해결 과제.
3. 기본 규칙과 기법. 지금-여기, 나와-너, 빈 의자, 양파껍질 벗기기.
4. 치료 목표. 체험 확장, 통합, 책임, 자립, 성장, 실존적 삶.
5. 알아차림-접촉 주기와 여섯 단계의 끊김.
6. 접촉경계 혼란. 내사, 투사, 융합, 반전, 자의식, 편향.
7. 수치심. 죄책감과의 차이, 수치심-죄책감 굴레, 치료적 접근.
