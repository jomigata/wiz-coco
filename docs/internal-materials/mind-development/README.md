# 심성개발을 위한 교류분석(TA) 프로그램

부제는 초급과정(TA 101 Course)이다. 저자는 우재현이고, 출판사는 정암서원이다. 1989년부터 쓰던 훈련 프로그램을 고친 책이다. 앞부분 서문은 1992년 10월이고, 제7판 서문은 2002년 2월 20일이다.

상태: `reference`. 검사 방법과 수치는 쓰지 않는다. 채점은 90문항, 2020-04-01 컷, 시간 60문항, 스트로크 25문항을 유지한다. 학파는 고전, 재결단, 커넥시스 세 개다. 설명 요지는 [explanations.md](./explanations.md)에 있다.

스캔은 `TA_001`부터 `TA_397`까지 397장이고 빠진 번호는 없다. 인쇄 쪽은 약 408쪽에서 끊긴다. 목차의 409쪽 이후는 스캔에 없다. 그 구간은 QC, 마케팅, 훈련실, 인터뷰, 성격 5형, TAOK, 상담, 타페트, 참고문헌, 자격증이다.
