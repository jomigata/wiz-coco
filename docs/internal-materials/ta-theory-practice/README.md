# 교류분석: 이론과 실제

1999년 2월 서문의 훈련자 매뉴얼이다. 부제는 교류분석 훈련프로그램: 훈련자 매뉴얼이다. 저자는 이도영, 김남옥, 추석호, 이수연, 김규식이다. 표지의 출판사명은 일부가 가려져 있어 적지 않았다.

상태: `reference`. 본문과 활동지 문항은 옮기지 않았다. 채점 기준으로 쓰지 않는다. 학파 3개(고전, 재결단, 커넥시스)에도 넣지 않는다.

스캔은 `관련서적\TA이론과실제`이다. 1부는 004–145번, 142장이다. 146–170번과 173번은 폴더에 없다. 2부는 171–392번 가운데 173번을 뺀 221장이다.
