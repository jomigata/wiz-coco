# 스트로크 체크리스트 25문항

출처는 `검사 - 스트로크체크리스트.hwp`, 제목은 `스트로크 분석(KTAA식)`이다. 상태는 `needs-confirmation`이다.

보기는 매우긍정 5, 약간긍정 4, 보통 3, 약간부정 2, 매우부정 1이다.

이론 노트의 스트로크 경제 5법칙, 스트로킹 프로필(주기·받기·요구하기·거부)과는 별도 문항지다. 법칙 문장을 이 25문항의 채점표로 바꾸지 않았다.

그래프에는 축 A–E와 `I→U`, `I→U`, `I←U`, `I←U`, `NO STROKE`가 있다. 어느 문항이 어느 축인지는 문장에 없어서 배정하지 않았다.

문항은 [items-25.json](./items-25.json)에 있다.
