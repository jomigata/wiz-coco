# 학지사 결과 샘플

출처는 `TA\학지사-결과샘플`이다. 상태: `reference`. 출판사 결과지 견본과, 243 문장을 결과지에 끼워 넣으려던 엑셀이다. 위즈코코 채점이 아니다. 견본의 점수, 해석 문장, 사람 이름, 연락처는 두지 않았다. 그림 파일 `정리본.psd`는 글이 아니라 읽지 않았다.

## 243 수정 시트

`학지사+243패턴 수정_20200111.xlsx`의 시트 `243패턴 수정_20190812`는 글자 코드 203개다. 보관 중인 202개는 모두 들어 있다. 비워 둔 41개 가운데 `ACCCB`만 이 시트에 있고, 나머지 40개는 없다. `ACCCB` 문장도 넣지 않는다. 41개는 그대로 빈다.

문장에는 정도를 고르는 빈칸이 들어 있다. 칸 번호는 대부분 (1)(2)(4)(5)라, 보관본의 네 단락과 번호가 같지 않다. 인쇄 번호로는 `CABAC`가 174와 194에 두 번 있고, 194는 `CBABB`와도 겹친다. 보관 키는 글자 코드다. 기존 파일에서 20번을 `AACAB`와 `CBBBA`가 같이 쓰는 규칙은 이 시트로 바꾸지 않는다.

## 결과지 구성 초안

같은 파일의 `자료입력조건`은 결과 페이지 목차다.

| 번호 | 칸 |
|---|---|
| 1 | 앞표지 |
| 2 | 243 이고그램 유형 |
| 3 | 개인의 전체적인 성격특성 |
| 4 | 종합적·개별적인 성격진단결과 |
| 5 | 직업 |
| 6 | 결혼생활 |
| 7 | 개선방안 |
| 8 | 기본적인 생태도 |
| 9 | 겉마음과 속마음의 비교 |
| 10–14 | 부정성 분석 CP, NP, A, FC, AC |
| 15 | 뒤표지 |

점수를 문장에 끼우는 초안 태그가 있다. 조건으로 적힌 값은 CP, NP, A, FC, AC, U−, U+, I+, I−와 출생년도, 성명, 거주지역, 직업, 학력, 결혼, 성별, 가족인원, 종교다. 앱 입력 항목으로 쓰지 않는다. 성격 강점, 청소년 성격, 아이젱크, 대인관계, 심리사회성, 네오, 스테이션, 우울, 스트레스, 자아개념, 마인드핏, 정서행동 시트는 비어 있거나 견본 PDF를 보라고만 한다.
