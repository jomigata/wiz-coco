# 심리검사 자료

출처는 `TA\자료-발표\_심리검사 자료`의 파일 15개다. 상태: `reference`. 위즈코코 채점은 [60문항 시간 구조화](../time-structuring/README.md)와 [90문항](../ego-ok/README.md), 2020-04-01 컷을 그대로 쓴다. 이 묶음의 문항 문장, 임상 컷, 해석 문장은 두지 않았다.

## 시간 구조화

`시간구조화_체크리스트.hwp`는 이미 비교용으로만 남은 [48문항](../time-structuring/v48-checklist.json)과 같다. 문장은 진술형이고, 여섯 칸의 흰 칸이 그 파일의 열이다. 맨 아래 합계 줄은 여섯 칸이 모두 비어 있어 문항이 아니다. 보기 1점 칸의 원문 오탈자 `강항 부정`도 그 파일과 같다. 60문항 질문형 점검표가 아니고, 45번 문장도 60문항의 확인 문장과 다른 문항이다. 채점에 넣지 않는다.
