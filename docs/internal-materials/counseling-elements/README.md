# 상담의 디딤돌

원제는 The Elements of Counseling, 4th Edition이다. 저자는 Scott T. Meier, Susan R. Davis다. 영어판 저작권은 2001년이고, 한국어판 저작권은 2003년이다. 옮긴이는 이동렬, 유성경이다. 발행은 시그마프레스, 2003년 11월 1일 초판 1쇄다. 역자 서문은 2003년 7월이다. 제4판이다.

상태: `reference`. 검사 방법과 수치는 없다. 채점은 바꾸지 않는다. 원리 문장과 대화 예는 옮기지 않았다. 설명 요지는 [explanations.md](./explanations.md)에 있다.

스캔은 `001.jpg`부터 `083.jpg`까지 83장이다. 본문은 양면이 한 장에 찍혀 있다. `[Originals]`는 002부터 083까지를 겹쳐 둔 사본이다.
