# 이고-오케이 타당도 9문항(99문항 은행) 변경 요약

**적용일:** 2026-10 · **은행 ID:** `ego-ok-99` · **코드:** `src/lib/egoOkValidity.ts`, `docs/internal-materials/ego-ok/items-99.json`

## 문항 수

- **99문항** = 성격 90 + 타당도 9 + **VRIN 5쌍** (전용 100번 문항 없음, 성격·F 문항 대립)
- 타당도 번호(오름차순): **9, 15, 26, 38, 48, 58, 68, 78, 88**

## 타당도 9문항 — 척도별 측정 영역

| 척도 | 번호 | 측정 요지 |
|------|------|-----------|
| **IMC** (성실도) | 9 | 현실·시간 지각 — 기본 상식 부정(무성의 전부 부정) |
| **IMC** | 38 | 신체·반사 — 갑작스러운 위험에 놀람 부정(무작위 클릭) |
| **IMC** | 68 | 생활 상식 — 과로·피로 시 휴식 필요 부정(일렬 낮은 점수) |
| **F** (비전형) | 26 | 정서 — 감정을 한 번도 느껴본 적 없음(감정 결핍·과장) |
| **F** | 58 | 인지 — 며칠 새도 완벽 집중(과대·비현실) |
| **F** | 78 | 신체 — 감기·피로를 단 한 번도 없음(비현실) |
| **L** (거짓말/포장) | 15 | 정서 위선 — 가까운 사람에게 짜증·투정 없음(성인 코스프레) |
| **L** | 48 | 성실 위선 — 피곤해도 게으름 없음(과장된 성실) |
| **L** | 88 | 관계 위선 — 섭섭함조차 없음(초월적 관용 코스프레) |

## 채점 공식 (5점 리커트, 1=전혀 그렇지 않다 … 5=매우 그렇다)

1. **IMC 무성의 판정:** **9·38·68** 중 **3점 이하**가 **2개 이상** → **무효**. 1개 → **주의**.
2. **F 왜곡 판정:** **26·58·78** 중 **3점 이상**이 **2개 이상** → **무효**. 1개 → **주의**.
3. **L 위선 판정:** **15·48·88** 중 **2점 이하**가 **2개 이상** → **도덕적 포장 주의**(종합 **주의**, L 단독 **무효 없음**).

4. **VRIN 일관성:** 아래 **5쌍**에서 두 문항 모두 **4점 이상**이면 불일치 1쌍. **2쌍 이상** 무효, **1쌍** 주의.

| 쌍 | 대립 요지 |
|----|-----------|
| **3 ↔ 49** | 자기 긍정(I+) vs 무가치감(I−) |
| **5 ↔ 60** | 타인 수용(U+) vs 반감·비판(U−) |
| **11 ↔ 46** | 침착·냉정(A+) vs 충동·즉흥(FC−) |
| **34 ↔ 56** | 통제·지배(CP−) vs 우유부단·주체성 부족(AC−) |
| **33 ↔ 26** | 호기심·열정(FC+) vs 「감정 1초도 없음」(F 타당도) |

코드: `EGO_OK_VRIN_PAIRS_99` · `src/lib/egoOkValidity.ts`

종합 판정: IMC·F·VRIN **무효**, L **주의** 중 최악 단계 반영.

## 비정상 시 설명 (99문항)

타당도·VRIN이 정상이 아니면 **해당 문항 번호 + 지문 핵심어**로 `issueBrief`·상담사 노트에 요약 표시 (`egoOkValiditySummaries.ts`).

## 배치

- 약 10문항마다 타당도 1문항 교차(블록 인터리빙)
- 말미 97~99는 **일반 성격** 문항 (`i_plus`, `i_minus`, `u_minus`)
