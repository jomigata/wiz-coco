## 2. 해결 방향 (권장)

1. **완전중복·고유사:** 같은 척도 안에서 **행동 장면**을 분리 (예: np− 「챙김」 vs 「대신 해결」 → 하나는 *가정*, 하나는 *직장*, 하나는 *거절 못하는 부탁*).
2. **주제중복:** 소분류(5문항)마다 **다른 촉발 상황**을 배정 — `item-subscale-diagnosis-ko.json` 5슬롯과 1:1 맞추기.
3. **i+ / u+ 「나는」 연속:** 10문항 중 **3~4문항만** 「나는」 유지, 나머지는 「대체로 ~하는 편이다」로 방어·사회적 바람직성 감소.
4. **쉼표:** 의미 단위가 바뀌는 지점(대비·원인·양보절) 뒤 1개 — 화면 2줄 규칙(41자↑)과 맞추려면 `@` 또는 `,` 후 줄바꿈.
5. **타당도 9:** 문장만 다듬고 **기대 반응·번호(9·15·26·38·48·58·68·78·88)** 유지.
