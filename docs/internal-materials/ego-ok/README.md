## 기준본 — 90문항

[items-90.json](./items-90.json)

출처는 `검사 - 종합 설문지 결과 기준치_2020.04.01.xlsx` 시트 `체크리스트`이다. 2026-09-30 확인으로 이 90문항을 기준으로 둔다.

- 페이크(성실도 반복) 문항은 넣지 않는다. 수정본 95문항 기준으로 빼는 번호는 26, 46, 54, 65, 93번이다. 90문항 시트에는 그 반복 문항이 원래 없다.
- 청소년·어린이 문장은 이 기준에 넣지 않는다. 그 문장은 [items-95-revised.json](./items-95-revised.json)에만 남아 있고, 상태 `not-adopted`이다.
- 준비물 파일의 `100문항` 설명과 `95문항` 시트도 기준이 아니다.

## 결과 기준 — 둘 다 사용

2026-09-30 확인: 5단계(A~E)와 243패턴 3단계를 둘 다 쓴다.

### 1) 수치 시트 — 5단계 A~E

이고그램은 성별이 다르다.

| 척도 | 남자 A / B / C / D / E | 여자 A / B / C / D / E |
|---|---|---|
| CP | 50~43 / 42~36 / 35~27 / 26~16 / 15~0 | 50~41 / 40~34 / 33~23 / 22~16 / 15~0 |
| NP | 50~47 / 46~43 / 42~36 / 35~27 / 26~0 | 50~48 / 47~44 / 43~35 / 34~29 / 28~0 |
| A | 50~47 / 46~43 / 42~35 / 34~25 / 24~0 | 50~45 / 44~41 / 40~30 / 29~22 / 21~0 |
| FC | 50~43 / 42~36 / 35~28 / 27~19 / 18~0 | 50~46 / 45~41 / 40~30 / 29~19 / 18~0 |
| AC | 50~43 / 42~35 / 34~27 / 26~16 / 15~0 | 50~46 / 45~41 / 40~29 / 28~18 / 17~0 |

오케이그램 U−, U+, I+, I− 차이값은 같다.

| 유형 | 차이값 |
|---|---|
| A | +7 ~ +50 |
| B | +3 ~ +6 |
| C | −2 ~ +2 |
| D | −3 ~ −6 |
| E | −7 ~ −50 |

차이값 식은 U− = AA+AB−AC, U+ = BA+BB−BC, I+ = DA+DB−DC, I− = EA+EB−EC 이다.

이고그램 부정성 백분율 표는 시트에 `Old`라고 적혀 있다. 5문항 만점 25 대비 A 100~76%, B 75~51%, C 50~31%, D 30~16%, E 15~0%이다.

원문 숫자는 [norms-sheet-2020-04-01.json](./norms-sheet-2020-04-01.json)에 있다.

243Plus는 CP·NP 합, A, FC·AC 합을 다시 나눈다. 합계 46~50 A³, 41~45 A², 37~40 A¹, 33~36 B³, 28~32 B², 24~27 B¹, 19~23 C³, 15~18 C², 10~14 C¹.

### 비연속성

같은 응답이 연속되면 감점이다. 5연속 4점×횟수, 6연속 6점, 7연속 9점, 8연속 13점, 9연속 20점, 10연속 30점, 이후 11~16연속은 10점씩 늘고, 17연속 이상은 100점×횟수다. 비연속성 = (100 − 감점 합)%. 시트 계산 칸의 `#REF!` 숫자는 쓰지 않는다.

### 인생태도

| 분류 | 조건 |
|---|---|
| 자기긍정 | (U+ − U−)가 −1~1 이고 (I+ − I−) > 1 |
| 자기부정 | (U+ − U−)가 −1~1 이고 (I+ − I−) < −1 |
| 타인긍정 | (U+ − U−) > 1 이고 (I+ − I−)가 −1~1 |
| 타인부정 | (U+ − U−) < −1 이고 (I+ − I−)가 −1~1 |
| 자타긍정 | 둘 다 > 1 |
| 자타부정 | 둘 다 < −1 |
| 자타평평형 | 둘 다 −1~1 |

`완벽한(66%이상)`으로 시작하는 끊긴 문장과, 시트에 남은 소수 계산값은 쓰지 않는다.

인구통계 코드 두 벌, 약관 문장, 14번 옆의 남는 문장은 확인에서 제외했다. 기준 입력 항목으로 넣지 않는다.

`교류분석 요약정리.xls`에는 인생태도를 `CP ? NP`, `FC ? AC`로 나누는 문장이 있다. 결과 계산은 위의 U·I 차이값과 5단계·243패턴을 유지한다. CP·NP 비교는 [이론 요약](../ta-overview/README.md)에만 있고, 확인 전에는 판정에 더하지 않는다.
