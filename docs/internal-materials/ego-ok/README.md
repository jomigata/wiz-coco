## 결과 기준 — 두 가지가 들어 있다

### 성실도·비연속성 (수정 시트)

성실도 쌍의 점수 차이: 1점 → 19점, 2점 → 14점, 3점 → 5점, 4점 → 0점. 신뢰성 = (100 − 이 감점 합)% 로 적혀 있다.

같은 응답이 연속되면 비연속성 감점이다. 5연속 4점×횟수, 6연속 6점, 7연속 9점, 8연속 13점, 9연속 20점, 10연속 30점, 이후 11~16연속은 10점씩 늘고, 17연속 이상은 100점×횟수다. 비연속성 = (100 − 감점 합)%.

이 감점표 오른쪽 계산 칸에는 `#REF!`가 있어, 예시 숫자가 깨져 있다. 규칙 문장만 남기고 깨진 칸의 숫자는 보관하지 않았다.

### 인생태도 (수정 시트 하단)

| 분류 | 조건 |
|---|---|
| 자기긍정 | (U+ − U−)가 −1~1 이고 (I+ − I−) > 1 |
| 자기부정 | (U+ − U−)가 −1~1 이고 (I+ − I−) < −1 |
| 타인긍정 | (U+ − U−) > 1 이고 (I+ − I−)가 −1~1 |
| 타인부정 | (U+ − U−) < −1 이고 (I+ − I−)가 −1~1 |
| 자타긍정 | 둘 다 > 1 |
| 자타부정 | 둘 다 < −1 |
| 자타평평형 | 둘 다 −1~1 |

원문은 `between 1 & -1`이라고만 되어 있어, −1과 1을 포함하는지는 표기만으로 확정하지 않았다. 마지막 줄 `완벽한(66%이상), 대체로(56~65%), 작으나마(45~55%)`는 문장이 끝나 있지 않다. 옆에 있는 0.589…, 0.701… 같은 소수와 56, 57은 표 규칙이 아니라 시트에 남은 계산값으로 보고 기준에 넣지 않았다.
