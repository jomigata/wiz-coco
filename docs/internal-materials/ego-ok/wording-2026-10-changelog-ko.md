## 종료 구간 순서 (인접 유사도 완화)

| 변경 | 내용 | 결과 |
|------|------|------|

## 검사 화면 줄바꿈 (2줄 가독성)

| 단계 | 규칙 |
|------|------|
| **원본 TSV** | 문장은 **한 줄**. 줄을 나누고 싶으면 `@`를 넣는다 (`쉼표,@다음 절`). 빌드 시 `@` → `\n`. |
| **자동 (`wrapReadingText`)** | `@`·`\n`이 없고 **전체 42자 초과**일 때만: 문장 **중앙 근처**의 `, ` 뒤에서 줄바꿈; 없으면 중앙 근처 **공백**에서 줄바꿈. |
| **앱 표시** | `text` / `readingText`의 `\n`을 `EgoOkQuestionReading`이 그대로 2줄로 렌더. (`egoOkQuestionBreaks.ts`의 `@`는 UI 편집용·빌드 TSV와 별개) |

**2026-10 반영:** 44번 문구·어순 확정 + `@`로 「지키며,」 뒤 줄바꿈. 49번 문구 동일, `@`로 「때면,」 뒤 줄바꿈.
