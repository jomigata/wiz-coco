# 99문항 화면 줄바꿈 기준

`scripts/build-items-99-final.mjs` 의 `wrapReadingText` 규칙.  
소스: `items-99-source.tsv` (한 줄 = 문항 1개, `@` = 강제 줄바꿈)

## 규칙 (우선순위)

| 순서 | 조건 | 화면 `text` / `readingText` |
|------|------|-------------------------------|
| 1 | `@` 포함 | `@` → `\n` (쉼표 뒤 의미 단위에서 수동 분리) |
| 2 | `@` 없음, 전체 **40자 이하** | 한 줄 |
| 3 | `@` 없음, **쉼표+공백 1개**, 두 줄 각 **42자 이하** | 첫 번째 `, ` 뒤에서 줄바꿈 |
| 4 | `@` 없음, **쉼표 여러 개** | 줄 길이 균형이 가장 좋은 `, ` 위치에서 분리 |
| 5 | 그 외 | 공백 기준 균형 분할 |

상수: `READING_SINGLE_LINE_MAX = 40`, `READING_LINE_MAX = 42`

## `@` 강제 줄바꿈 문항 (9개 — 타당도 전부)

| No | `@` 위치 (앞절 끝) |
|----|-------------------|
| 9 | …사람이라도, |
| 15 | …볼 때, |
| 26 | …분노를, |
| 38 | …끝마쳤을 때, |
| 48 | …밀려 있어도, |
| 58 | …생각하는 일이, |
| 68 | …들으면, |
| 78 | …착각해, |
| 88 | …행동에, |

## `@` 없음 — 빌드가 쉼표·길이로 자동 2줄 (예)

| No | 비고 |
|----|------|
| 3 | 성격과 삶의 방식 — 첫 `, ` 뒤 분리 (40자 초과) |
| 4, 10, 20, 31, 51, 85 등 | 동일 규칙 3~4 |

## 갱신

문구·`@` 변경 후: `npm run build:ego-ok-items-99`
