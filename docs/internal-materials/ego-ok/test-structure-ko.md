# TA 이고-오케이그램 검사의 기본 구조

1. 5개의 이고그램(CP, NP, A, FC, AC)과 4개의 오케이그램(U−, U+, I+, I−)으로 구성되며, **대분류**에 해당한다.
2. 9개의 그램들은 각각 positive, negative로 2가지 형태로 구분되며, **중분류**에 해당한다.
3. 각 그램 9가지는 positive 5문항, negative 5문항(총 10문항)으로 구성되며, 5문항마다 세부 진단 목표(소분류)를 둔다.
4. 타당도 관련 문항은 **9문항**이다(검사 진행 순서상 블록 인터리빙).

채점·척도 배정은 `items-99.json` / `egoOkQuestions.ts`를 따른다.
