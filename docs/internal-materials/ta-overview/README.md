## 이번 파일에서 새로 넣은 이론

검사 문항에 없던 내용이다. 결과 수치를 자르는 규칙으로는 쓰지 않는다.

- 학파: 고전(이고그램·스트로크·3P), 재결단(굴딩), 커넥시스(쉬프, 재양육·수동성). 본문은 `3개 학파`라고 쓰고 항목은 네 개다.
- 이고그램 모양 이름: W·M·N·역N, 산·V·U·역U, 경사, 크레바스 5, 돌출 5, 두제이 우위 유형.
- 오케이그램을 읽는 비교: CP와 U−, NP와 U+, FC와 I+, AC와 I−의 크고 작음.
- 스트로크 종류와 경제 5법칙, 게임 공식, 드라마 삼각형, 12금지령, 드라이버 5+주의하라, 에누리 4단계.

## 이미 있는 기준과 다른 곳

확인 전에는 아래 문장으로 검사 결과를 판정하지 않는다. 항목은 [확인요청](../확인요청.md) 2차에 있다.

1. 시간 구조화 나열 순서가 검사와 다르다. 이 노트는 폐쇄·의식·활동·잡담·게임·친교(친밀) 순이고, 확정된 검사 척도는 폐쇄·의식·잡담·활동·게임·친교다. 같은 노트 안에서도 의식은 `(P,AC)`와 `(P,A)`, 잡담은 `(C,P)`와 `(C,A,P)`로 적혀 있다. 바람직한 시간 배분으로 `폐쇄>의식>활동=친밀>잡담>게임` 마름모가 적혀 있다.
2. 인생태도 계산이 다르다. 기존 기준은 U+−U−, I+−I− 차이값이다. 이 노트의 오케이-이고그램 진단은 `CP ? NP`, `FC ? AC` 비교다. 언스트 OK목장 4분면은 이름과 특징만 있고 점수식은 없다.
3. 제목이 `이고그램 전형 23패턴`인데, 적힌 유형을 세면 지그재그 4, 기형 4, 경사 2, 크레바스 5, 돌출 5로 20개다.
