## 이번 파일에서 새로 넣은 이론

검사 문항에 없던 내용이다. 결과 수치를 자르는 규칙으로는 쓰지 않는다.

- 학파 3개: 고전(이고그램·스트로크·3P), 재결단(굴딩), 커넥시스(쉬프, 재양육·수동성). `3개 학파를 넘어서`와 친교·친밀은 학파 목록에 넣지 않는다.
- 이고그램 모양 이름: 아래 대표 형태. 23개로 닫지 않는다. 이후 파일의 추가 이름은 [이고-오케이 형태 목록](../ego-ok/patterns-44.json)에 있다. 역U는 명랑 낙관형(CP·AC B)과 기탄없이 말하는 형(CP·AC C)을 둘 다 둔다. CP 결핍 이름은 느슨한형이다.
- 스트로크 종류와 경제 5법칙, 게임 공식, 드라마 삼각형, 12금지령, 드라이버 5+주의하라, 에누리 4단계.

## 확인 반영

1. 시간 구조화의 활동·잡담 순서와 마름모는 이론이다. 검사 척도 순서는 바꾸지 않는다.
2. 인생태도는 [이고-오케이 기준](../ego-ok/README.md)대로 NP−CP를 U+−U−, FC−AC를 I+−I−로 표기한다.
3. 이고그램 형태는 원문에 붙은 이름만 기록한다. 개수를 23으로 맞추지 않는다. 역U 두 이름과 느슨한형은 2026-10-01에 확인했다.
4. 친교·친밀은 3개 학파에 넣지 않는다. 검사 6번 척도 이름은 친교다.
