# 교류 사례 스캔

이 폴더에는 책 표지가 없다. 쪽머리에 제2장 구조 분석, 제3장 교류 패턴 분석이 있다. 각주에는 한국교류분석연구회가 보인다. 저자·출판사·해는 이 스캔만으로 확정하지 않는다.

상태: `reference`. 대화 예와 문항은 옮기지 않는다. 이고그램 표의 ○ △ ×와 손글씨 답은 채점으로 쓰지 않는다. 채점은 90문항과 2020-04-01 컷을 유지한다. 설명 요지는 [explanations.md](./explanations.md)에 있다.

스캔은 `_0305`부터 `_0326`까지 22장이다. 그 앞 번호는 이 폴더에 없다.

| 파일 | 인쇄 쪽 | 보이는 것 |
|---|---|---|
| 0305 | 40–41 | 안쪽 대화의 예 |
| 0306–0309 | 62–69 | 성인·중고 이고그램 표, 그래프, 읽는 법 |
| 0310–0311 | 70–73 | 우위 유형 그림, 낮은 상태 |
| 0312–0314 | 74–78 | 자기 개조, 3장 표지 |
| 0315–0326 | 81–103 | 교류 유형과 방향. 103쪽에서 끊김 |

41쪽 다음이 62쪽이고, 78쪽 다음이 81쪽이다. 그 사이는 이 폴더에 없다.
