# 자기분석 결과 보고서

출처는 `자기분석 결과 보고서.hwp`이다. 2011-11-19 한 사람(송재화)의 글이다. 상태는 `kept-separate`이다. 채점 기준으로 쓰지 않는다.

이고그램과 스트로크 그래프는 그림이라 숫자가 문장에 없다. 글에서 읽을 수 있는 내용만 적는다.

| 절 | 날짜 | 글에 있는 내용 |
|---|---|---|
| OK 이고그램 | 2010-04-10, 2011-11-10 | 1년 7개월 뒤에도 N형 |
| 대항각본(스트로크) | 같은 두 날짜 | 스트로크 양이 낮아짐 |
| 대항각본(드라이브) | 2011-11-10 | 17점을 향한 `열심히 노력하라`, `강해져라` |
| 인생태도 | 2011-11-10 | I'm OK & You're OK 방향이면서 네 태도를 모두 가짐 |

원문은 [sample-2011.txt](./sample-2011.txt)에 있다. 사례로만 둘지, 그래프 숫자가 다른 파일에 있는지는 확인 전이다.
