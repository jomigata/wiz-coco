# 교류분석 상담의 적용

원제는 Developing Transactional Analysis Counselling이다. 저자는 Ian Stewart이고, 영어판은 1996년이다. 한국어판 저작권은 2009년, 학지사다. 옮긴 단체는 한국교류분석임상연구회이고, 역자 서문은 회장 임원선 이름이다.

상태: `reference`. 검사 수치로 쓰지 않는다. 30단계는 상담 진행의 제안이고, 채점 키가 아니다. 사례와 관찰표는 옮기지 않았다. 설명 요지는 [explanations.md](./explanations.md)에 있다.

스캔은 `DTAC-000`부터 `DTAC-384`까지 359장이다. 없는 번호는 6, 12, 16, 17, 36, 50, 51, 70, 78, 86, 96, 124, 146, 156, 164, 192, 202, 203, 248, 258, 296, 306, 332, 344, 356, 372다. 있는 파일의 번호는 인쇄 쪽과 같다.

## 목차

1부는 교류분석의 원리다. 이론 개요 19쪽, 치료의 기본 원리 37쪽.
