# 온라인 검사 설명 및 활용

출처는 `온라인검사 설명 및 활용 2020.01.04.pptx`, 55장이다. 상태는 `reference`이다. 한국교류분석협회 상담사용 설명이고, 대부분 화면 그림이다. 채점 컷이나 문항 본은 없다.

## 목차에서 읽히는 절차

1. 실시 방법. 사무실 컴퓨터와 모바일 웹·스마트폰.
2. 이고-오케이 검사 진행. 온라인 전용과, 온라인에 수기 결과를 더하는 경로. 개인정보 입력, 수기 결과 입력.
3. 결과 확인, 재확인, 인쇄, 파일 저장.
4. 내담자 인증키로 결과 다시 보기. 상담사 관리 페이지. 2019년 10월 이전 인증키는 별도 목록.
5. 인증키 검색과 목록 순서.
6. 내담자용 결과 보기 선택. 일괄 저장과 개별 저장.
7. 결과 보기·인쇄 종류 선택.
8. 인증키 종류와 구매, 전송. 개인용, 상담사용, 수기용(온라인). 문자 안내와 이메일로 인증키.
9. 결과지에 상담사 이름·전화 넣기. 별명과 정보 수정.
10. 상담사용 관리 실습. 장단점, 개선, 문의.

현재 이고-오케이 90문항과 시간구조화 60문항 기준은 이 설명으로 바꾸지 않는다.
