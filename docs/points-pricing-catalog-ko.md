# WizCoCo 포인트 단가표

> **2025-09 적용** — UI·API·차감 표기는 **포인트**, Firestore DB는 기존 **크레딧(정수)** 필드 유지  
> **1포인트 = 100원** · **DB 크레딧 1건 = 100포인트** (= 10,000원)

## 환산 규칙

| 구분 | DB (레거시) | 포인트 | 원화 |
|------|-------------|--------|------|
| 기본 단위 | — | 1 | ₩100 |
| 검사 지갑 1건 | 1 credit | 100 | ₩10,000 |
| AI 지갑 1건 | 1 AI credit | 100 | ₩10,000 |

## 검사(포털) 차감

| 기능 | 포인트 | 비고 |
|------|--------|------|
| 내담자 생성 + 이메일/휴대폰 **발송 성공** | 5 / 명 | 실패·미발송 시 0 |
| 나의코드 **재전송** — 휴대폰 | 1 / 건 | 이메일만 0 |
| 나의코드 **재전송** — 이메일 | 0 | |
| 공개 claim (휴대폰) | 5 | 발송 성공 시 (최초 발송과 동일) |
| 첫 1명 발송 체험 | 0 | 최초 1명만 |

## 포인트 유효기간 (lot)

- Admin 지급 시 **+1일 / +7일 / +1달** 누적 또는 **캘린더 만료일** 지정
- Firestore `counselorCreditLots` — 지급 lot별 `expiresAt`, `pointsRemaining`
- 차감 시 **만료일이 가장 빠른 lot부터** (FEFO), 만료 lot은 자동 소멸

## AI 기능 차감

| 기능 | DB AI credit | 포인트 | 원화(참고) |
|------|--------------|--------|------------|
| AI 상담 메시지 | 0 | 0 | ₩0 (파일럿 무료) |
| 상담 세션 요약 | 0 | 0 | ₩0 (파일럿 무료) |
| 검사 결과 AI 해석 | 4 | 400 | ₩40,000 |

| AI 종합 리포트 | 5 | 500 | ₩50,000 |
| 재생성 | 50% | 50% (포인트 기준 반올림) | — |

## 충전·구독 상품

상담사 B2B2C 충전 팩·월 구독(스타터/프로) 및 파일럿 고정 지급량(검사 500p / AI 200p)은 **제거**되었습니다.  
포인트는 **Admin 수동 지급** 또는 **기관·협회 협의**로 운영합니다.

## API 필드 (하위 호환)

- `balance` — DB 크레딧 정수 (유지)
- `pointsBalance` — UI용 포인트 (신규, **표준 잔액 단위**)
- `wonPerPoint` — 100 (원)
- `pointsDelta`, `pointsBalanceAfter` — 원장 행 (신규)
